# 首页 (Home)

## 💡 核心思想

本页面为考生登录后的第一视觉锚点，**100% 像素级对齐风格 B（Apple 钛金微光风）预览标准**：

1. **暮光通顶问候顶栏 (`hm-header`)**：
   - 依据考生本地时区呈现动态问候语（“下午好”/“上午好”/“晚上好”等）。
   - 展示当前机构名称 `institutionName` 与 Apple 蓝微光圆角头像 `hm-avatar`（考生首字拼音/汉字提取）。
2. **大圆角立体 Banner 轮播 (`hm-banner`)**：
   - 32rpx 超大圆角外框与柔和悬浮阴影（`$shadow-float`）。
   - 内置高透毛玻璃分类微章（`hm-banner__tag`）与半透明深空渐变遮罩。
   - 底部指示器为 Apple 灵动条形长短过渡胶囊动效（`hm-dots`）。
3. **为你推荐 · 钛金试卷卡片流 (`hm-card`)**：
   - 采用大圆角卡片布局（`40rpx 36rpx` 呼吸内衬），右上角内嵌漫反射柔光气泡（`hm-card__glow`，按不同题型分类亮起红/蓝/橙不同色调）。
   - 卡片核心呈现**三联独立指标条**（`题量`、`限时`、`总分`），字体均加粗特大。
   - 底部左侧显示截止时间（紧急试卷高亮红并伴随呼吸红点 `card-pulse`），右侧配备 Apple 纯正极简胶囊按钮（`立即开考` / `去参加`）。
4. **全模态数据状态闭环**：
   - **加载中**：展示 3 组带有流光微动效的 Apple 骨架屏（`hm-skel`）。
   - **清空态**：渲染 Apple 琉璃金色五角星勋章（`hm-medal`）与漫反射光环，恭喜考生清空待办。
   - **列表态**：严格过滤已交卷记录，只展示未作答/待考题卡，调用真实后端 `GET /api/v1/member/banners` 与 `GET /api/v1/member/member-tasks`。
