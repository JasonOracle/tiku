# 个人中心页 (Profile)

## 💡 核心思想

本页面为考生个人数据、资产汇总与系统控制面板，**100% 像素级对齐风格 B（Apple 钛金微光风）预览标准**：

1. **通顶立体个人名片 (`pf-card`)**：
   - 采用深空流体暮光背景（`pf-aurora`），搭配高透玻璃质感名片（`backdrop-filter: blur(20px)`）。
   - 左侧为 Apple 蓝微光圆角头像（`pf-avatar`，附带绿色认证微标勾 `✓`），右侧为姓名、企业认证学员标签、脱敏手机号与当前所属机构。
2. **三联资产数据看板 (`pf-stats`)**：
   - 扁平化陈列 `已测场次`、`平均得分`、`我的收藏`。
   - 数据真实从后端实时计算提取，点击可无缝跳转到对应列表。
3. **Apple 原生拟物图标族与分组列表 (`pf-row`)**：
   - 原生矢量微图标族：五角星（`pf-glyph--star`）、月亮（`pf-glyph--moon`）、铃铛（`pf-glyph--bell`）、垃圾桶清理（`pf-glyph--clean`）、信息圆环（`pf-glyph--info`）。
   - 内置丝滑交互拨动开关（`pf-row__toggle`）用于深色模式与测评通知。
   - **红线约束**：严格遵循用户指令，**完全剔除“切换机构”**，保持企业学员上下文纯粹一致。
4. **退出登录与版本信息**：
   - 底部配备浅红半透圆角退出登录按钮（`pf-logout`），弹窗二次确认后清空 Pinia 状态并重定向至登录页。
