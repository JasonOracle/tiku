# MyTasksView 我的测试组件文档

## 💡 核心思想

C 端学员「我的测试」中心视图，负责学员个人测试生命周期管理与进度追踪：

1. **统一顶部视效与命名**：
   - 顶部导航标题由旧版「我的任务」升级为「我的测试」，与底部 TabBar 及业务场景全面对齐。
2. **规范的三态切换与动态计数（三态流向闭环）**：
   - **进行中 (`ongoing`)**：任务当前处于发布状态，且在开放时间窗口内（当前时间 ≥ `start_time` 且 ≤ `deadline`），学员尚未交卷。
   - **未开始 (`upcoming`)**：任务设置了未来的 `start_time`，当前时间尚未到达开考时间，学员不可作答（行动按钮呈现置灰锁定）。
   - **已参加 (`completed`)**：学员已经提交试卷（包含 `submitted` 已交卷、`pending_verification` 待核验、`verified` 已核验），提供分数查看与试卷回顾。
   - 每个 Tab 右侧均实时统计当前状态下的测试数量徽章。
3. **高定悬浮卡片体系（与首页高保真对齐）**：
   - 采用纯立体弥散阴影与微边框悬浮卡片；
   - 动态展示试卷所属分类（`cat-badge`）与限时胶囊（`mode-tag timed`），彻底废除硬编码的“练习模式”；
   - 真实呈现题目数量、总分、及格线三连指标；
   - 根据所处状态动态回显开考时间、截止时间或交卷时间。
4. **行动指令清晰分流**：
   - 进行中：渐变蓝紫「开始」按钮，点击立即开考 (`/task?task_id=...`)；
   - 未开始：浅灰锁定「未开始」按钮，防误触；
   - 已参加：显示最终得分并在右侧提供绿色「查看」按钮，点击直接精准定向至测试结果报告页 (`/report?record_id=...`)，杜绝因重复开考拦截导致的空白报错。

## 💻 使用示例

```vue
<!-- 在 router/index.ts 中作为二级路由挂载 -->
import MyTasksView from '../views/my-tasks/MyTasksView.vue';

const routes = [
  { path: '/my-tasks', component: MyTasksView, meta: { title: '我的测试' } },
];
```
