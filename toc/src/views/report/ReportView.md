# ReportView 考试分析报告组件文档

## 💡 核心思想

展示考试或练习完成后的全维度可视化复盘报告。

包含三大核心区域：
1. **成绩汇总面板**：SVG 环形得分进度圈、动态及格判定胶囊（已交卷/已核验/审核中）、答对/答错题目统计卡片以及耗时统计。
2. **AI 智能评语与解析（若有）**：展示服务端批阅或 AI 给出的综合评语建议。
3. **我的作答明细（逐题深度复盘）**：
   - **题型徽章外显**：根据 `type` 兼容解析并外显单选题、多选题、填空题、简答题、判断题胶囊。
   - **客观题选项全景比对**：遍历选项列表，自动比对学员选项与标准答案，支持三态高亮标签（`我选了` 蓝标、`正确答案` 绿标、`错误` 红标）。
   - **判断题自动补齐**：当后端未配发 options 选项时，前端自动兜底生成 `A. 正确 / B. 错误` 两项供高亮比对。
   - **填空题逐空对照**：题干连续下划线渲染为 `<u>` 占位，下方通过 `fill-pair` 按空位次序清晰展开「第 N 空：我填 vs 标准答案」。
   - **简答题与解析回显**：展示学员主观答题文本与标准答案，底部回显 `explanation`（题目解析与采分要点），若无解析则显示“暂无解析”占位。

### 数据流与防坑逻辑

- **时间耗时兜底**：`time_spent` 在接口未返回或为 0 时隐藏该统计块（`hasTime` 计算属性），避免显示“0秒”造成学员认知混乱。
- **答案归一化（Normalize）**：判断题的标准答案可能是 `A/B`、`T/F`、`TRUE/FALSE` 或 `正确/错误`，比对引擎统一将其规整映射为 `A/B` 进行等值判断，彻底杜绝匹配失效。
- **填空题拆分匹配**：学员答案若为逗号/分号分隔的字符串，自动切分为数组与标准答案数组对齐长度，防止数组越界。
