## 追加修复：`/admin` 打开却是 C 端界面

- **现象**：用户访问 `http://127.0.0.1/admin`（**无结尾斜杠**）打开的是 C 端页面。
- **根因**：nginx `location /admin/` 只匹配带结尾斜杠的路径。`/admin` 未命中该前缀路由，
  掉入 `location /` → root 指向 C 端产物 → `try_files ... /index.html` 兜底返回 C 端页面（200，非 404，故不易察觉）。
- **修复**：`nginx.conf` 在 `/admin/` 之前新增
  `location = /admin { return 301 /admin/; }`，并加变更日志注释。
- **生效方式**：**无需重建容器**——`nginx.conf` 是单文件绑定挂载，改完直接
  `docker exec tiku_nginx nginx -t && docker exec tiku_nginx nginx -s reload` 即可。
  （注意与"改挂载路径必须重建容器"区分开：那是目录挂载的场景。）
- **验证**：`/admin` → 301 Location `/admin/`；`/admin`、`/admin/`、`/admin/exams` 均落地 B 端（title=tob，js=/admin/assets/*）；
  `/` 仍为 C 端（js=/assets/*）。
- **已同步文档**：`progress.md` 变更日志 + 接手检查清单新增「网关访问约定」第 4 条，并刷新冻结时间戳。

### 本次沉淀的关键技术经验（复用价值高）

1. **playwright-cli 的 ref 会跨会话漂移**：`ref`（如 `f2e213`）在**每次 snapshot 后重新编号**，
   Element Plus 异步渲染的弹窗内元素编号**必然**与上次不同 → **严禁硬编码 ref**。
   正解：`run-code --filename=<js>`，用 `page.getByRole('textbox', { name: '姓名', exact: true })`
   角色定位器；`run-code` 的参数是一个 **async 函数**，会被 `(page)` 调用。
   注意 `getByRole('textbox', {name:'姓名'})` 会与"搜索手机号/姓名/昵称"输入框冲突 → 必须 `exact: true`。
2. **浏览器无法跨工具调用存活**：每次 pwdrive 调用 = 一次完整会话；登录态用
   `state-save/state-load` 落盘复用。可用 API 登录 + 手写 storageState（键：
   `tiku_tob_token/username/role/tenant/super`，origin `http://127.0.0.1`）**批量造登录态**，
   比走 UI 登录快得多。
3. **所有业务接口必须带 `X-Tenant-ID` 头**（登录除外），否则 400「缺少 X-Tenant-ID」；
   该头同时是租户隔离闸门：非成员租户 → 403「无该企业访问权限」。
4. **`/admin/ai/*` 需 admin 及以上**；学员(member)调用会 403「角色权限不足」。
5. **AI 出题/组卷是"确认卡"两段式**：聊天只出卡片，必须点
   `确认生成题目并入库`（题目） / `确认创建试卷`（组卷）才落库；
   卡片确认后**仍留在转录里**并显示「已入库/已处理」绿标，且按钮仍在 → 不能以"按钮仍存在"判断未执行。
6. **AI 助手正文抓取**：会话 DOM 为 `.assistant-row` / `.user-row`；等待完成的判据是
   文本不再含 `思考中|正在思考|生成中` 且连续两次不变（否则会在"正在思考中..."处提前判定）。
7. **账号矩阵勘误**：超管实际为 `13800000000 / GodPass123`（剧本写的 `10000000000/123456` 是错的）；
