# toc-new 双风格 UI 审美升维与全状态静态设计方案 (improveUI.md)

## 0. 方案核心宗旨
在**绝对不改动当前正式业务逻辑与接口契约**的前提下，依据全局安装的 `design-taste-frontend` 顶级审美标准，在 `toc-new/src/` 下创建**两个独立风格的静态设计页面文件夹**供挑选对比。

每个风格均包含 **全部 7 大页面**，且**全部注入高度饱满的真实边界数据**（包含多种做题状态、全题型、及格/不及格/审核中、多状态切换器），让演示与选型一目了然。

---

## 1. 两套设计风格定位与核心参数表 (The Dials)

| 维度 | 风格 A：Linear 极客冷灰风 (`preview-linear`) | 风格 B：Apple 钛金微光风 (`preview-apple`) |
| :--- | :--- | :--- |
| **设计理念** | **硬核、工程、高效、克制** (类似 Linear / Raycast / GitHub Next) | **温润、轻奢、呼吸感、触控质感** (类似 iOS 18 / VisionOS / 扣子) |
| **核心色板** | 纯白 `#FFFFFF` + 冷灰梯队 (`#F8FAFC`, `#0F172A`) + 极客电光蓝 `#1D63FF` 单一重音 | 钛金冷白 `#FBFBFD` + 柔和暖灰边框 + 暮光微渐变 (`#1852E0` -> `#0A3299`) + 琉璃光泽 |
| **圆角与轮廓** | 精致微圆角（卡片 12px ~ 14px），高对比度 1px 细线边框（`rgba(0,0,0,0.06)`） | 大圆角（卡片 18px ~ 20px），多层漫反射微弥散阴影，浮雕微立体内描边 |
| **状态徽章** | 扁平极简矩形圆角、低饱和度色底、等宽数字代码感 | 拟物微胶囊、毛玻璃柔光（Backdrop Blur）、通透微渐变底 |
| **三大表盘** | `VARIANCE: 5` · `MOTION: 4` · `DENSITY: 5` (秩序严谨、高信息承载) | `VARIANCE: 8` · `MOTION: 7` · `DENSITY: 3` (艺术错落、强呼吸感) |
| **存放路径** | `toc-new/src/preview-linear/` | `toc-new/src/preview-apple/` |

## 2. 覆盖的 7 大核心页面与极端真实数据清单

为了确保演示的真实感与对比度，两套风格的每个页面均提供**高度饱和的模拟数据与全边界状态**：

### 2.1 首页 (Home)
- **多轮播 Banner**：高质感企业培训 Banner，带轮播指示器与微渐变遮罩。
- **待考列表丰满数据**：
  - 卡片 1：【严苛限时】星雅教育-2026年全员安全生产与合规考试（限时 30 分钟 · 倒计时仅剩 2 小时 · 红色紧急徽标）。
  - 卡片 2：【综合测评】教务教学质量标准化综合测试（100题 · 不限时 · 综合能力金标）。
  - 卡片 3：【专项技能】AI 教学辅助与出题大模型实操评估（5题 · 附带AI推荐标签）。
- **演示切换器（右上角浮动小胶囊）**：一键切换 **「丰满列表态」** / **「任务清空成就态（勋章插画）」** / **「网络加载骨架屏」**。

### 2.2 我的测试 (Records)
- **「进行中」Tab**：展示已答 3/5 题的测评卡片，高亮“继续答题”按钮与剩余时间进度条。
- **「未开始」Tab**：展示“预约开考：明日 09:00”与带有灰色锁头置灰按钮的计划试卷。
- **「已参加」Tab（核心全状态）**：
  - 记录 1【及格高分】：100分大字 · 绿色徽标 · 答题用时 18 分钟 · 击败 98% 考生。
  - 记录 2【审核安全态】：客观题已批阅 · 黄色胶囊“AI/人工批阅核验中” · 暂无分数。
  - 记录 3【未及格态】：48分红色大字 · 红色未及格胶囊 · 提示“待补考”。

### 2.3 在线考场 (Exam)
- **全 5 类真实题型 100% 同屏或切题体验**：
  1. 单选题：4 选项带点击微缩放与选中变色反馈；
  2. 多选题：方角复选框，演示已选中 `A, C` 组合；
  3. 判断题：双胶囊大按钮「正确 / 错误」；
  4. 填空题：双空位输入框，演示已输入部分内容；
  5. 简答题：大文本输入框，带字数统计（128/500）与自动聚焦。
- **60vh 答题卡抽屉**：1~20 题矩阵面板，标明：当前题、已作答、未作答、已标记。
- **切屏防作弊告警**：模拟切屏弹出危险告警提示弹窗。

### 2.4 成绩报告 (Report)
- **出分看板**：
  - 风格 A 为仪表盘式数据矩阵看板；
  - 风格 B 为深空极客微渐变夜空看板（带微漫反射光晕）。
- **逐题复盘**：
  - 正确选项：**翠绿浅底 + 绿色边框 + 绿勾 `✓`**；
  - 错选选项：**绯红浅底 + 红色边框 + 红叉 `✕`**；
  - 标准答案：**极客蓝微色底加粗**；
  - 考点精解卡片：带展开收起动画的解析与考察点标签。
- **安全审核态一键切换**：支持切换查看态 B 下防泄题保密插画和答案锁定表现。

### 2.5 个人中心 (Profile)
- 头像徽章、企业员工认证标、星雅教育教务中心专属认证。
- **三大核心数据看板**：已测测评 `16 场`、平均得分 `91.4`、错题收藏 `7 道`。
- 快捷入口：我的收藏、深色模式微开关、清除缓存、关于弹窗、安全退出（隐式单租户绑定，无多余切换机构干扰）。

### 2.6 我的收藏 (Favorites)
- 错题集卡片流：展示错题学科分类、当时错误答案与标准解析，支持一键移除。

### 2.7 登录页 (Login)
- 风格 A：极简高冷代码流登录面板，浮雕微阴影输入框。
- 风格 B：沉浸式企业品牌暮光光晕登录面板，单租户隐式绑定无感知极速登录。

## 3. 落地推进计划步骤

1. **第 1 阶段：目录搭建与设计系统 Token 建立**
   - 新建 `toc-new/src/preview-linear/` 与 `toc-new/src/preview-apple/`。
   - 分别创建两套风格专属的 SCSS 样式变量文件（色彩系统、阴影、圆角、字体层级）。

2. **第 2 阶段：落地 风格 A (Linear 极客冷灰风) 7 大页面**
   - 编写全套 7 个页面，内置全部边界状态与浮动状态切换器。
   - 保持 Props 与真实后端模型 100% 同构。

3. **第 3 阶段：落地 风格 B (Apple 钛金微光风) 7 大页面**
   - 编写全套 7 个页面，内置同样丰富的数据与不同层级的视觉微质感。

4. **第 4 阶段：注册路由与对比导航台**
   - 在 `pages.json` 中配置独立访问路径：
     - Linear 风格：`/preview-linear/index/index` 等；
     - Apple 风格：`/preview-apple/index/index` 等。
   - 在应用入口挂载「双风格全屏切换导航浮窗」，让你能随时在浏览器里一键直达任意页面对比！

5. **第 5 阶段：构建验证与验收汇报**
   - 执行 `pnpm type-check` 与 `pnpm build:h5`，确保全套代码零报错、零冲突。
   - 提供直达链接供你在浏览器中比对挑选。
