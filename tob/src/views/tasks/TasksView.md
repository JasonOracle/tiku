# TasksView 试卷管理与智能组卷视图组件文档

## 💡 核心思想
实现 B 端试卷资产管理、多维度考试数据洞察与智能编排：

1. **现代企业级 SaaS 列表质感与视觉动线重构（参考图高保真实现）**：
   - **无硬框纯立体弥散阴影（Elevated Island Shadow）**：完全消除表格硬框与大卡片生硬线条，改用多层复合柔和弥散阴影（`0 10px 30px -5px rgba(0,0,0,0.05)`），令大卡片如悬浮岛般自然浮起。
   - **仅第一行表头专属着色**：仅首行表头单元格赋予优雅的淡蓝灰背景色（`#f1f5f9`）与细分割线（`#e2e8f0`），下方数据行保持纯净全白通透平铺，彻底还原图2的高定呼吸感。
   - **列宽防折叠与防变形**：所有表头强制设定 `white-space: nowrap !important; word-break: keep-all !important;`，ID 列（80px）、题目数列（100px）、总分列（95px）、随机排列（110px）全部留足弹性宽度，彻底根除“I D 坚排折行”或字形压缩问题。
    - **微组件胶囊化与状态切换（Pills, Switches & Dots）**：
      - 上架状态采用“**直观交互式 `el-switch` 开关组件**（开启为经典品牌蓝并内嵌字样 `已上架`，关闭为浅灰并内嵌字样 `待上架`）”，彻底解决胶囊纯静态排版导致用户不知道可以点击切换的痛点；
      - 开关接入 `before-change` 异步生命周期拦截：开启上架直接调用发布并提示；关闭下架弹出确认警告对话框，点击“确认下架”后才执行更新，防止管理员误触下架造成线上考试不可用；
      - 分类采用中性灰无边框轻质胶囊；
      - 随机排列等阴性数据采用灰白超轻胶囊（`否`），降低视觉噪音。
   - **行动指令强弱分级**：
     - 【人工批阅】：按需显示原则。仅当试卷存在待批阅员工答卷且数量大于0（`row.pending_count > 0`）时才渲染**醒目亮橙渐变胶囊按键**（标注 `(N份)`）；无待人工批阅的试卷不展示该按钮，避免界面冗余与误触；
     - 【详情】：降级为轻盈的文本图标链接，主次分明不争抢视觉焦点。
   - **统一查看详情与双 Tab 数据洞察（操作列精简收敛）**：
     - 彻底废除旧版操作列多余分散的 `[数据]` 按钮，与 `[查看详情]` **合二为一**。
     - **表格列彻底去教育化**：将旧的「创建老师」统一修正为标准企业级「创建人」，精准对接后端返回的 `creator_name` 字段，杜绝短横杠 `—`。
   - **Tab 1: 试卷数据**：
     - **基础档案卡片**：展示试卷标题、所属分类、创建人、考试时长限制（限时/不限时）、总分与及格分数线、阅卷模式（管理员人工终审 / AI全自动审批）与题目出题排序模式（随机/固定）。
     - **题目分析胶囊**：动态计算并渲染单选、多选、判断、填空、简答等各类题型的道数与总题数。精准兼容 `single_choice`、`multiple_choice`、`judge`、`fill_in`、`short_answer` 等后端枚举。
     - **试题全景流（免折叠展开）**：按序号顺序直观展示所有题目的题干描述与分值。选项采用 `getNormalizedOptions` 自动解析对象数组 `[{key, text}]` 或字符串列表 `["A. xxx"]`，杜绝空白框；**正确答案选项以高保真浅绿背景 + 绿色描边 + 勾选图标高亮标注**；填空与主观题直观展示标准参考答案与解析。
   - **Tab 2: 考试数据（对齐多租户企业员工模型与待核验闭环）**：
     - **待核验预警横幅 (Alert Banner)**：当存在待人工终审主观题 (`verify_pending > 0`) 时，在 Tab 顶部高亮渲染橙色提示栏，明确注明尚有未批阅试卷及当前及格线，并内置 **`[立即批阅 (N份)]`** 按钮，直接在详情弹窗内拉起核验抽屉；核验完成后自动热刷新当前报表，形成闭环。
     - **4 大 KPI 核心指标**：参考人员总数、全员平均得分、全员最高分、综合考核及格率。
     - **成绩分数段分布**：以 90~100分（优秀）、80~89分（良好）、60~79分（及格）、<60分（不及格）四大区间展示人数及百分比进度条，注明包含初评数据。
     - **员工考核成绩明细（精致专业表格）**：配置深灰蓝立体表头（`#f1f5f9`）、序号列与完整边框；若员工处于 `pending_verification` 待审状态，得分标记「初评」徽章，判定结果显式展示橙色「待人工核验」高光胶囊，杜绝未审定前机械误判为“不及格”。
     - **优雅空状态（Empty State 兜底）**：当试卷刚创建尚无员工提交或处于草稿时，以轻量矢量插画优雅提示：“暂无考生作答记录，试卷发布后作答数据将在此实时生成”，杜绝计算异常与空图表白屏。

2. **试卷创建与编排弹窗（高定卡片仪表盘与单题原地改分）**：
   - **摒弃冗杂补丁条**：彻底废除原有突兀刺眼的亮蓝色大提示框，换用高质感浅灰底色卡片（`Settings Strip`），实现配置内聚。
   - **基础属性行栅格化**：试卷名称、所属分类、发布状态（草稿/直接上线）三字段横向对齐，消除表单割裂。
   - **规整开关与时间/及格微计算**：
     - 限时作答（内联分钟微调）、随机排列、首页推荐以小卡片项目整齐排开；
     - 考试时间区间（起止时间选择）与及格比例（滑块 + 百分比胶囊）合并至下部综合条，并直接内联展示 `总分 N 分 ➔ M 分及格` 的即时换算标签，一览无余。
   - **题目原地改分与轻量化操作列**：
     - 题目编排表格支持每道题通过 `el-input-number` **原地微调独立分值**，并即时联动总分和及格线毫秒级重算；
     - 上移、下移、删除按键合并至操作列，告别繁重的单题外层多重框线；
     - 保存试卷时将包含 `{id, score}` 的题目集提交后端持久化，实现个性化试卷组卷分值。

3. **独立选题模态框与排序/批量控制**：
   - 支持表格批量勾选后一键批量移除，以及 `▲/▼` 按钮灵活调整作答顺序。
   - 题库选择弹窗以独立模态框呈现，具备题型过滤与搜索，支持一键批量加入试卷。

4. **✨ AI 智能一键组卷与审阅清单所见即所得**：
   - 极简两项核心输入：组卷需求 + 试卷分类。
   - **交互防误触遮罩（Loading Overlay）**：点击「开始 AI 创建」后，整个弹窗内容区自动覆盖高质感半透明 `v-loading` 遮罩（提示：“AI 智能组卷编排中，正在调优题干与选项，请稍候...”），完全冻结需求输入框、分类选择与高级选项折叠面板，彻底防止生成期间用户误触修改导致脏数据。
   - 参考私有文库：动态感知已向量化的企业文库切片，自动关联切片溯源；若需求不相关则智能脱钩。
   - **大模型原创多题型生成**：根据用户自然语言需求（单选/多选/判断/填空/简答），输出结构化选项（`options: [{key, text}]`）与规范化正确答案数组（`answer`）。
   - **原地审阅高质感卡片流**：弹窗生成后原地无缝展开审阅清单（`.ai-review-list` 与 `.ai-review-card`），题干、分值标签独立排布，选项带浅灰底色胶囊，正确答案绿色高亮加粗前置 ✔，核对无误后一键保存。

5. **删除与安全闭环**：
   - 草稿 `draft` 或已下架 `archived` 且无学员提交记录的试卷允许彻底物理删除；
   - 处于上架发布的试卷需先下架；已有学员作答记录的试卷为保护资产与答卷历史不可物理删除。
