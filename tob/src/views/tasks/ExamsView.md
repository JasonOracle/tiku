# ExamsView 试卷管理与智能组卷视图组件文档

## 💡 核心思想
实现 B 端试卷与组卷管理。
1. **分类与规则**：新建与编辑试卷时支持选择分类、控制答题限时、通过 `el-slider` 滑块选定及格百分比（0-100%），支持“随机题目顺序”控制 C 端答题排列。
2. **动态总分计算**：试卷总分实时根据已选题目的默认分值（score）累加得出，及格分数由 `Math.ceil(总分 * 百分比 / 100)` 自动向上取整计算。
3. **独立选题模态框与排序/批量控制**：
   - **【已选题目列表】**：展示试卷当前已加入题目，支持 `checkbox-group` 复选批量移除，以及 `▲/▼` 按钮灵活上下调整作答顺序。
   - **【独立题库选择弹窗】**：以独立 `ElDialog` 模态框呈现全站题库，具备题型过滤与搜索，支持勾选复选框一键批量加入试卷。
4. **✨ AI 智能一键组卷**：
   - **极简两项核心输入**：首屏主表单保留「组卷需求」与「试卷分类」（必填项，打开弹窗自动回显默认分类）。
   - **参考私有文库 (选填多选)**：仅当检测到出题人名下有已解析完成（`status === 'done'`）的文档时，在试卷分类下方呈现该多选下拉框；教师可自由勾选 1 份或多份讲义教材，大模型将严格依据选中文档切片出题，生成题目自动携带切片溯源；若无文档则完全隐藏，零视觉干扰。
   - **方案A智能脱钩机制**：若用户勾选的私有文库文档与组卷需求不相关，底层向量检索通过相似度阈值（$score < 0.45$）自动剔除脱钩，大模型切换为通识命题，绝不给题目附带张冠李戴的伪溯源切片。
   - **智能时间兜底**：考试时间下沉至“高级选项”，未填写时系统自动赋予当前时间起 7 天的开放区间，保证 C 端考试状态流转闭环。
   - 支持设置题目难度单选（简单/中等/困难，默认中等）。
   - 自然语言解析强化：支持自动识别明确指定了题型构成（如“3道单选、2道判断”）及通用数量描述（如“生成关于金融风险的6道题目”）。
   - 答题限时开关 + 及格比例 Slider 滑块（及格线在生成后进入编辑查看页按已选试题总分与及格比 `Math.ceil(总分 × 及格比 / 100)` 动态计算）。
5. **已发布只读查看与状态流转**：已上架/归档的试卷支持通过“查看详情”以只读模式预览试卷基本信息与题目明细。
6. **删除与安全闭环**：
   - 处于非已上架状态（草稿 `draft` 或已下架 `archived`）且无任何学员提交记录（零作答）的试卷，均允许直接物理删除；
   - 正在上架发布的试卷需先下架再删除；已有学员作答记录的试卷为保护作答数据不可物理删除。
